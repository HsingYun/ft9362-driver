# FT9362 指纹匹配算法设计

状态：面向正式认证的目标设计，尚未实现和完成样本验证。设备数据提供后，根据同传感器评估结果确定算法、参数与阈值。当前驱动仍使用原始帧模板和旁路匹配，不能将本文要求视为现有能力。

## 1. 目标与约束

为 FocalTech FT9362（USB `2808:0752`）实现可靠录入、1:1 验证和允许拒绝未知手指的 1:N 识别。算法选择以实际认证效果为依据，不限定传统方法、学习方法或有证据支持的组合方法。

| 约束 | 要求 |
| --- | --- |
| 认证结果 | 优先满足目标误接受率，再比较误拒绝、录入成功率与资源成本 |
| 传感器 | 面向当前 40×152 窄幅输入，处理位置、角度、压力及局部覆盖变化 |
| 存储 | 正式模板保存特征信息，不保存完整原始帧或灰度图像 |
| 部署 | 独立 C++ 共享库，通过 C ABI 接入；仅使用 C/C++ 标准库，不引入任何第三方库 |
| 实现规模 | 只保留有实测收益的组件，不为候选算法预建通用插件框架 |
| 行为边界 | 质量不足、未匹配、执行错误与取消必须分开表达，不得默认成功 |

按本机小图库和 CPU 可运行规划资源。目标误接受率、允许误拒绝率、图库上限、尝试次数以及延迟／内存预算尚需确定；它们是验收条件，不能从当前采集成功推导出来。

身份匹配与活体检测分别评价。本文不宣称具备已验证的防伪能力，也不承诺特征模板不可逆或已匿名化。

### 无第三方库的边界

此约束适用于算法 C++ 源码、构建及运行：不链接、静态嵌入或以仅头文件方式引入 OpenCV、Eigen、BLAS、ONNX Runtime、TensorFlow Lite、LibTorch、NBIS 等库。检测、滤波、描述、几何估计、序列化和必要的神经网络前向计算均自行实现。C/C++ 标准库、系统数学库及编译器运行时属于基础运行环境，不将“无第三方库”解释为禁止正常的 C++ 运行时。

现有 C 驱动的 libfprint／GLib 依赖与 Python 工具依赖不属于算法库。离线训练、标注和参考对照可使用独立环境中的工具，但不得成为算法库的构建、安装或运行依赖。CNN 的训练产物是参数数据，部署端不加载训练框架。

论文和已有实现用于研究与结果核对，不代表引入对应库。独立实现不复制第三方源码；如需复用源码，必须重新审查依赖约束与许可证。最终构建还需检查包含路径、链接项和共享库依赖，防止依赖通过静态库或头文件隐式进入。

## 2. 输入、校验与质量

### 数据事实

布局依据见[协议文档](protocol.md)和 [Windows 移植参考](windows-reference.md#71-三种长度及原始图像布局)：

| 项目 | 当前工程约定 |
| --- | --- |
| 完整采集帧 | 12,166 字节 |
| 图像载荷 | 偏移 4，长度 12,160 字节 |
| 图像布局 | 152 行，每行 40 个小端 16 位采样 |
| 已有实测反馈 | 设备能够采集并显示指纹图像 |
| 待确认 | 有效位深、脊线尺度、设备朝向、固件差异及跨按压稳定性 |

16 位存储单元不等于 16 位有效精度。协议逻辑响应与当前保存格式存在一字节差异，不能直接删字节来消除差异。图像显示正常也不能代替协议完整性或身份匹配验证。

### 处理要求

处理过程须区分三个问题：

- **帧是否有效：** 检查实际接收长度、状态及已确认的协议校验规则。损坏帧作为采集错误，不进入匹配。
- **图像是否可用：** 评估有效覆盖、饱和、噪声、纹理清晰度等。不能仅用亮度或特征点数量判断质量。
- **两次观测是否匹配：** 在各自图像可用后比较身份信息。单张图像清晰不代表与录入区域存在足够重叠。

协议头尾不参与特征提取。原始数据先保留精度，再按所选算法转换为所需格式；截断、归一化、滤波、增强和重采样均须有实际收益，并固定端序、坐标系、边界与数值规则。算法不得隐式使用 GUI 的临时显示选项。

需要固定采样尺度的方法，应确认实际分辨率或脊线尺度；不因常见指纹数据集采用某个 DPI 就套用该数值。放大和补边不增加身份信息，增强后的伪纹理不能作为通过依据。运行时和离线评估必须执行相同预处理。

## 3. 算法流程与职责

正式算法需要完成下列业务过程；这不是要求每一步都单独拆成函数或模块。

| 过程 | 输入 | 输出与约束 |
| --- | --- | --- |
| 质量判断与预处理 | 有效采集图像 | 可用观测或明确的质量重试原因 |
| 特征生成 | 可用观测、算法资源 | 临时特征及必要质量信息 |
| 录入更新 | 本次特征、录入会话 | 接受／重试、进度或完成模板 |
| 比较 | 探测特征、参考模板 | 可判定的匹配证据与分数，或未匹配／错误 |
| 决策 | 分数、校准配置、图库 | 验证结果或原图库中的身份索引 |
| 持久化 | 已完成的录入结果 | 有版本、边界和兼容性约束的特征模板 |

特征可以是细节点集合、局部描述子、纹理表示、固定向量或它们的经验证组合。特征生成和比较也可以由联合模型完成，但必须能够使用持久化特征模板，不能在部署时隐式要求恢复或保存录入原图。

特征布局、相似度度量、质量估计和评分属于算法选择；取消、错误传播、资源释放及结果语义属于公共契约。先确定有效的算法，再落实必要的数据结构，不同时引入全部候选的运行时依赖。

## 4. 录入设计

录入的目标是取得足够稳定、覆盖实际使用姿态的身份信息。有效按压次数、每次是否使用多帧及模板是否融合，依据覆盖收益、成功率和耗时确定。

录入会话至少需要：

1. 判断当前样本质量，必要时请求重新按压。
2. 区分持续按住与独立按压；相邻帧可以用于选帧或稳定性分析，不能无条件增加进度。
3. 判断新样本与已接受数据的身份一致性，并识别高度重复或无新增价值的观测。
4. 按验证过的覆盖与完成条件提交模板；达到时间或次数上限仍不满足时明确失败。
5. 在取消或错误时释放临时数据，不持久化半成品。

身份一致性检查由所选方法实现，不强制建立几何关系图。无法可靠确认的样本应重新采集，不能为扩大覆盖而将任意不同区域合并。测试必须包含录入中混入其他手指的情况。

存储多个独立样本、融合特征、建立局部参考坐标或拼接后提取特征均可评估。只有融合确实改善完整认证流程且未引入错误累积时才采用；若过程需要原图，原图仅存在于受控的临时录入数据中。

## 5. 位置变化、匹配与决策

### 位姿与重叠

两次扫描不要求像素坐标一致，算法需要处理重叠区域出现在不同位置的情况。允许采用特征对应、细节点拓扑、相关对齐、位姿不变表征或联合学习，不能假定某一种描述子自动解决全部平移和旋转。

使用显式对应关系时，需要检查其唯一性、支持区域、分布和几何一致性，避免重复脊线或很小区域造成高分。RANSAC、投票、图匹配等都是可选实现，不是固定架构要求。使用整图表征或联合评分时，则应通过偏移、旋转和重叠分组测试证明其鲁棒性，不能只看整体准确率。

位姿模型应与观测变化相符。旋转和平移可以作为起点；样本若证明存在显著弹性形变，可评估受约束的形变模型，但须验证其没有通过过度变形抬高异指分数。不能为了得到高分无限增加变换自由度。

当共同纹理不足、对应歧义过大或证据不可用时，不应产生肯定身份结论。多次录入可以增加覆盖机会，但不能保证任意按压都可识别。

### 评分与聚合

距离、相似度、内点数量和模型输出都不是可直接复用的认证阈值。每个算法及其预处理配置分别校准，不能跨描述子、模型版本或设备条件混用分数。

多样本比较可采用最高分、稳健统计、特征融合后的单次比较或经标定的评分融合。先评估完整决策效果，再确定聚合规则；不预先绑定最高分或某种回归模型。保留原图库索引，避免过滤或排序后返回错误身份。

| 场景 | 外部结果 |
| --- | --- |
| 1:1 验证 | 达到已校准的接受条件才匹配 |
| 1:N 识别 | 选择符合接受条件的身份，否则返回未匹配；不能总取最高分 |
| 空图库 | 未匹配 |
| 探测质量合格但证据不足／分数未达标 | 未匹配，不因比较失败无限重试 |
| 探测图像质量不足 | 明确的可重试结果，服从调用方次数与时间限制 |
| 不兼容模板、资源失败或非法输出 | 明确错误，不伪装成未匹配或成功 |
| 取消 | 丢弃动作结果并完成取消，动作只结束一次 |

1:N 的未知手指拒绝、不同手指之间的歧义、图库大小以及整个登录的尝试策略均需单独评估。第二名分差只是候选规则，不是所有算法都必须增加的门槛。

## 6. 模板与兼容性

模板采用有界的版本化格式，载荷由最终算法确定，不强制固定向量、二进制描述子或细节点格式。逻辑上至少记录：

- 模板格式、算法和兼容性版本。
- 影响特征可比性的预处理配置，以及存在时的模型标识。
- 必要的传感器布局／尺度信息、样本数量和特征数据。

同一权重下仅调整判定阈值未必改变模板格式；改变特征提取方式、采样模式或模型则通常影响可比性。模板兼容标识与判定配置分别管理，明确哪些更新必须重新录入，不凭版本名称猜测兼容性。

具体格式需要规定端序、字段与长度上限、有效数值及所有权，不能直接序列化 C++ 结构体。解析未知版本、异常长度、非有限浮点数和无效结构时失败。多模板图库遇到不兼容项时须有明确策略和测试，不能静默按空特征继续匹配。

不保存原始帧或完整灰度图像；特征本身仍按敏感生物信息处理。目标设计不包含静默在线模板更新。如引入更新机制，必须另外评估误匹配导致的污染、回滚与版本管理。

## 7. 算法选型范围

以下是按解决问题分类的研究范围，不是封闭清单，也不是要求全部实现。新的方法只要满足数据、模板、部署和验收约束，都可以纳入。

| 方法类别 | 可评估方向 | 针对本传感器的判断重点 |
| --- | --- | --- |
| 细节点与拓扑 | 端点／分叉点提取、方向与邻域几何；NBIS 等可作为参考 [1] | 窄幅图像是否提供足够可重复的细节点，尺度和边界条件是否满足 |
| 通用局部特征 | BRISK、ORB、AKAZE、SIFT 等检测／描述与匹配 [2][3] | 有效点分布、描述子边界、重复脊线歧义和跨按压稳定性 |
| 脊线与纹理 | 方向场、频率、滤波响应、纹理编码 | 局部区域的区分能力，对压力、干湿和灰度变化的敏感性 |
| 相关与图像配准 | 相位相关、归一化相关或迭代对齐等 [4] | 能否稳定估计重叠和位姿；配准高分不等于身份匹配 |
| 学习特征 | 局部／全局描述子、细节点网络、固定或空间化表征 [5][6][7] | 训练覆盖、样本成本、跨会话泛化、模板与 CPU 成本 |
| 联合与组合方法 | 联合位姿和匹配、受约束形变、必要的评分融合 [8] | 收益是否超过增加的数据、依赖、推理和维护成本 |

需要录入原图参与运行时比较的方法，只能作为离线对照或配准辅助；进入正式方案前，必须给出符合存储约束的特征表示。传统与学习方法也可以组合，但每个组件要有独立的收益证据，不能把多条规则任一通过就接受视为天然更准确。

### 窄幅输入的专项检查

对局部方法，分别统计检测点、成功描述点和有效匹配点，区分检测失败、边界剔除与匹配失败。以 BRISK 为例，OpenCV 会删除描述邻域越界的关键点，40 像素宽度下须检查采样尺度；缩小邻域保留更多点也可能损害区分能力 [3]。这些参数必须由开发数据决定，而不是只以点数多少为目标。

对学习方法，检查下采样后是否还保留足够横向信息、旋转增强是否符合真实姿态，以及跨区域样本是否被错误地强制视为等价。局部描述子的监督需要同一物理位置对应，不能把同一根手指的所有局部点都当作正样本。

对所有方法，都要测试少量共同区域、平行脊线、无重叠、明显形变及低质量输入。关键点响应、网络置信分数、相关峰值均需验证，不能自行解释为认证概率。

## 8. CNN 局部特征候选

本节优先研究**轻量全卷积局部描述子 + 空间一致性匹配**，保留逐块裁剪方案作为对照。选择依据是整图共享计算、保留位置关系以及减少旋转裁剪造成的覆盖损失；这不是已经证明的准确率优势。下面的网络是本工程提出的待验证配置，最终结构、参数与接受条件仍由设备样本确定。

整图联合生成局部特征可参考 [D2-Net](https://arxiv.org/abs/1905.03561)，局部重复性与可区分性的区分可参考 [R2D2](https://arxiv.org/abs/1906.06195)。两者的通用图像实验不证明 FT9362 的效果；本方案不采用它们的网络、权重或第三方实现。

### 特征与输入

整幅 40×152 图像执行一次共享卷积，在每个特征位置产生局部描述子，随后选择有限个位置并保存其原始坐标。不对整图做全局平均，也不将全部纹理压成一个身份向量。

1. 根据第 2 节确定的有效精度执行固定强度映射与截断，保留无效、饱和和背景区域的掩码；映射配置由开发数据确定，训练与运行一致。
2. 使用完整图像计算特征图。每个输出位置同时检查其原图支持范围，不能将卷积补零当作真实纹理。
3. 在支持有效的位置中排除明显无纹理观测，再按质量、空间间隔和分区覆盖选择至多 64 点。点数是工作量上限，不是必须凑满的目标。
4. 记录原图坐标与归一化描述子。网格坐标仅提供采样位置，不保证两次采集的格点对应同一物理位置；训练和匹配需容忍采样偏移。

方向一致性仅作观测信息，不作为硬性保留条件：平行脊线可能清晰但缺乏区分力，端点、分叉附近的方向变化也可能包含有价值的信息。预研先使用确定的质量与覆盖规则；只有具备合适监督且实验表明有效时，才增加预测匹配可靠性的分支。其输出也不直接解释为认证概率。

### 固定前向网络

批量大小为 1；表中尺寸为高×宽×通道，与传感器宽×高的写法区别。3×3 卷积采用互相关、每侧补零 1、显式偏置和 ReLU；1×1 投影不补零，保持线性输出。

| 层 | 配置 | 输出 |
| --- | --- | --- |
| 输入 | 固定预处理后的完整图像 | 152×40×1 |
| 卷积 1 | 3×3，1→16，步幅 1 | 152×40×16 |
| 卷积 2 | 3×3，16→24，步幅 2 | 76×20×24 |
| 卷积 3 | 3×3，24→24，步幅 1 | 76×20×24 |
| 卷积 4 | 3×3，24→32，步幅 1 | 76×20×32 |
| 卷积 5 | 3×3，32→32，步幅 1 | 76×20×32 |
| 描述子投影 | 1×1，32→32，步幅 1 | 76×20×32 |
| L2 归一化 | 每个位置沿通道归一化；近零或非有限向量无效 | 每位置 32 维 |

总步幅为 2，卷积感受野为 17×17。以原图像素中心为整数坐标，输出行列 `(v, u)` 对应原图 `(x, y) = (2u, 2v)`，支持范围为中心向各侧扩展 8 像素。完整有效图像中，严格排除越界支持后最多保留 68×12 个位置；背景掩码会进一步减少数量。若增加滤波或局部归一化，其额外邻域也必须计入有效支持，不能继续沿用 17×17 的边界判断。

该配置含 26,096 个参数，float32 权重约 102 KiB；单幅卷积约 4,008 万次乘加，不含预处理、归一化、选点和匹配。在逐层执行、复用工作区的安排下，同时存活的相邻层激活最大约 523 KiB；这是张量需求估算，实际分配布局、输入、掩码、权重及模板内存另计。共享计算降低重复工作，但其激活内存大于逐块执行，必须实测 CPU 延迟和峰值内存。

17 像素感受野和 32 维描述子均属待验证配置。前者是否覆盖足够脊线结构取决于实际尺度；增大感受野会增加边界损失，缩小则可能降低区分能力。总步幅为 2 也可能损失细节，需与更高分辨率配置做受控比较，不能只按计算量选型。

C++ 只实现固定结构需要的 3×3／1×1 卷积、ReLU、L2 归一化及必要采样，使用连续数组和固定执行顺序，不编写通用张量框架或模型图解析器。先核对 float32 标量语义，再按实测瓶颈考虑量化、SIMD 或其他优化；参数、算子或归一化改变后重新验证描述距离和认证表现。

### 旋转、偏移与边界

普通卷积不天然旋转不变。优先使用真实按压角度范围内的旋转增强和跨按压对应训练，直接学习可比较的描述子；不默认对每个点提取两个方向。实验需按旋转角度分组，包含 180° 朝向变化的适用性评估，不能以整体指标掩盖某些角度完全失效。

若单次前向计算的描述子不足以处理所需角度范围，再评价有限方向视图或方向归一化。它们需要额外计算、旋转后的有效掩码及回到原图的坐标变换；不能重复计数同一物理位置，新增匹配机会还需重新校准阈值。几何验证只能检查已经找到的对应，不能恢复描述子阶段遗漏的正确对应。

训练覆盖亚像素平移与不同采样相位，按已知映射在特征图上进行双线性采样并重新归一化，排除插值支持无效的位置。推理中的定位误差计入几何容差；仅在有实测收益时增加有界的局部对应细化。补边、插值与旋转都不能增加传感器实际观察到的纹理。

### 训练与导出

训练时对两幅图像使用共享权重，在有效重叠区域提取有可靠物理对应的特征作为正样本；仅有“同一手指”标签不足以监督局部对应。合成变换可以给出精确对应，但还需真实跨按压样本，覆盖压力、干湿、噪声和形变。对应标签须考虑遮挡与形变，配准伪标签必须抽查，避免把错误对应学成特征。

预研损失采用单位向量的对比损失：正对最小化平方欧氏距离，负对最小化 `max(0, margin - distance)²`。间隔、采样比例与难负样本策略在开发集确定。异指相似脊线属于必要负样本；同指不同位置只有在确认并非同一物理区域后才可作负样本，避免标签冲突。按人员划分数据，不以部署用户的身份类别限制可录入手指。

训练记录须包含预处理、网络版本、随机种子、数据划分、优化器及训练配置；以跨会话匹配与认证表现选择模型。单独评价重复平行脊线、端点／分叉附近和边缘区域，检查描述子是否塌缩或仅反映纹理方向。禁止只以训练损失收敛或局部分类准确率作为交付依据。

导出为项目自有的固定布局权重数据：格式版本、网络／预处理标识、各层长度及 float32 权重和偏置。明确字节序、权重排列及每层输出尺寸；加载时拒绝错形状、越界、缺失和非有限数据，不导入 ONNX 或任意模型图。权重可随算法库打包为只读数据；若使用独立资源文件，库只加载与编译结构匹配的资源，不在运行时下载。

离线导出参考结果，逐层核对 C++ 输出、最终描述距离以及阈值附近的匹配结果。绝对／相对数值容差必须明确，跨 CPU 的微小误差不能导致不可控的边界行为。

### 模板、录入与匹配

每个录入样本保存有效区域的紧凑覆盖信息、选中点的原图坐标／质量及每点一个 32 维描述子。float32 描述子在 64 点上限下占 8 KiB／样本，坐标、覆盖及格式头另计；无需保存完整特征图或原图。方向字段只在最终算法确实使用方向时加入。模板数量由录入收益与存储预算决定，结构和维度变化须更新兼容性标识。

录入按第 4 节收集独立按压，并通过本候选的匹配流程确认一致性；选留清晰、具有新增覆盖的样本，暂不对未配准特征取平均。没有可靠对应的新区域不直接加入。模板完成条件、样本上限和失败条件随评估冻结。

探测图像执行一次整图特征提取，以归一化描述子的欧氏距离比较点对，再执行第 10 节的对应筛选、几何校验和评分。1:1 比较一个身份下的全部录入样本；1:N 复用探测特征，在原图库中逐一比较并保留身份索引。候选方案采用身份内最高有效样本分数，阈值按实际样本数量和图库规模校准。

上述距离匹配作为对照；下面的 attention 候选替换对应生成与对应权重计算，继续使用几何验证和相同的外部结果契约。两者分别校准，部署时采用选定方案，不以任一路径通过就接受。

若有效支持过少、描述子跨按压不稳定、旋转范围不满足需求，或满足资源预算必须削减到无法认证的规模，应调整或淘汰此候选。未能取得可靠训练对应和足够训练身份时，不将随机权重或通用图像模型直接作为正式指纹算法。

### 裁剪块对照与验证项目

对照方案保留 24×24 裁剪块、脊线方向归一化及两个相差 180° 的方向。其网络为五个 3×3 卷积，通道依次 `1→16→16→32→32→64`，步幅依次 `1、2、1、2、1`，每侧补零 1；前四层使用 ReLU，末层线性输出，经 6×6 空间平均和 L2 归一化得到 64 维向量。它与全卷积方案分别训练、校准，不共用权重或模板格式。

该对照约有 34,864 个参数，单块约 207 万次乘加；64 点、双方向约为 2.65 亿次乘加。旋转裁剪可能需要约 34 像素宽度，严格方向筛选可能损失有价值位置，空间平均也可能削弱结构布局。这些是需测量的问题，不能预先当作准确率下降的结论。

比较时固定数据划分、录入和尝试策略，分别报告特征覆盖、对应正确率、完整认证表现、模板、内存及 CPU 延迟。针对共享计算、感受野、下采样、选点和方向处理做必要的受控实验，避免把两个不同配置的整体结果直接归因于某一层设计。

实现检查除逐层数值对照外，还包括特征图到原图的坐标映射、有效掩码传播、亚像素采样与归一化、旋转后坐标还原及近零描述子处理。全卷积方案优先于裁剪块方案开展研究，是否优于 BRISK 或其他候选仍按完整设备评估决定。

### Attention 匹配候选

优先研究在稀疏特征之间加入小型交叉注意力匹配器：利用周围结构和另一幅图像的特征消除重复脊线歧义。参考 [SuperGlue](https://arxiv.org/abs/1911.11763) 和 [LightGlue](https://arxiv.org/abs/2306.13643) 的学习式对应思路，不直接采用其网络或自然图像权重；指纹领域的联合位姿与身份研究见 [8]。这些资料不构成本传感器的效果证明。

| Attention 位置 | 作用 | 研究安排 |
| --- | --- | --- |
| CNN 通道／空间加权 | 调整特征或区域权重 | 独立可选实验，不与匹配器同时默认加入 |
| 单幅稀疏特征自注意力 | 编码同一观测中的结构关系 | 作为匹配器上下文步骤，验证对局部覆盖变化的敏感性 |
| 两幅稀疏特征交叉注意力 | 联合寻找对应与排除歧义 | 优先预研，与相同 CNN 特征的距离匹配作对照 |

#### 固定结构与输入

每侧输入至多 64 个点，每点包括 32 维 CNN 描述子、原图坐标和质量信息，并提供有效点掩码。坐标以传感器中心为原点，两个轴使用相同尺度归一化，保留几何比例。坐标编码用于表达结构，不预先奖励绝对坐标相近的点；通过平移、旋转和部分重叠训练避免学习错误的位置先验。

预研结构采用宽度 32、2 个注意力头、2 个处理块。每块按自注意力、双向交叉注意力、逐点前馈层执行；前馈层为 `32→64→32`，中间使用 ReLU，各子层采用前置 LayerNorm 和残差连接。坐标与质量经小型逐点映射进入特征。具体规模是实验配置，不承诺增加层数会改善认证。

两侧使用共享参数，双向交叉更新读取同一轮更新前的特征，避免执行先后改变结果。每头维度为 16，注意力使用 `softmax(QKᵀ / sqrt(16))V`；这只是上下文聚合，不直接作为点对应或认证结论。输入点排序不应影响输出对应关系，掩码点不参与归一化或汇聚。

模板仍保存独立提取的 CNN 描述子、坐标和质量。交叉注意力产生的特征依赖正在比较的另一幅图像，只存在于此次比较中，不回写模板。1:N 可复用探测 CNN 特征，但每个参考样本都需要执行交叉匹配；不能跨参考对象复用已经交叉更新的特征。

#### 无对应点与匹配输出

普通 softmax 即使面对完全不同的手指，也会给候选分配权重，因此输出必须明确包含“无对应”：

1. 将更新后的两侧特征投影后计算点对分数矩阵，并由逐点输出头为每个点预测无对应分数；这些参数均参与训练。
2. 每行在全部有效参考点与该探测点的无对应选项之间归一化；每列在全部有效探测点与该参考点的无对应选项之间归一化。无效填充点始终排除。
3. 仅保留双向最佳且两侧均优于无对应选项的点对，再应用经校准的最低对应权重。可用行、列概率的几何平均定义权重 `p_ij`；它不是身份概率，也不是已校准的独立对应正确率。
4. 点对保持一对一，送入第 10 节的刚体估计、残差与覆盖检查。空点集或没有足够对应时返回无匹配证据，不强行分配。

此分配规则是本工程的预研设计，不声称复现 SuperGlue 的最优传输或 LightGlue 的完整实现。它允许任意数量的点没有对应，不需要为了填满匹配矩阵而接受重复纹理。

通过几何门槛后，attention 候选的样本分数暂定为 `S_attention = (m / min(n_probe, n_reference)) × mean(p_ij)`，其中均值只包含唯一几何内点。空集不计算均值；支持数量、覆盖和残差门槛继续适用。该评分独立标定，不能将 `p_ij` 代入距离公式或沿用距离匹配阈值。身份内样本聚合、未知手指拒绝和歧义处理沿用第 5、10 节。

#### 训练与评估

先冻结 CNN 与选点规则，仅训练匹配器，以分离特征变化和 attention 的收益。监督包括可靠的跨按压对应、确定无对应的点、异指、无重叠及重复脊线困难负例；标签不确定的区域忽略，不直接标为无对应。正对应须在点集内可表达，处理重复候选和一对一标签冲突。

预研目标为两个方向的对应／无对应分类损失，控制正对应和无对应样本的权重，防止模型通过拒绝所有点降低损失。训练覆盖不同点数、点顺序、有效区域、位姿与形变；位置编码不提供天然旋转不变性。若后续联合微调 CNN，应重新导出特征提取版本并检查模板兼容性，不能与冻结特征的实验混为一组。

除完整认证指标外，检查真实对应召回率、错误对应率、无对应点拒绝、不同重叠比例及身份交换后的结果一致性。没有可靠对应监督时，attention 不能替代缺失的训练数据。它也不能恢复未被传感器观察到的区域，或挽回特征提取阶段已经丢失的信息。

#### C++ 实现与资源

固定实现矩阵乘法、逐点线性层、ReLU、LayerNorm、残差及带掩码的稳定 softmax；不依赖 BLAS、Eigen 或推理框架。softmax 在有效项中减去最大值后求指数，空输入提前返回；LayerNorm 的方差定义、分母下限及权重布局须与训练端一致。全部掩码、极端分数和非有限输出均需有明确处理，不能产生 NaN 后继续判定。

64×64 的单头分数矩阵为 4,096 个 float32，约 16 KiB；这只是一个矩阵，双向、多头、前馈层、权重和工作区另计。单层交叉聚合成本随 `N×M×D` 增长，线性投影与前馈另计；总成本还随处理块数、录入样本数和图库大小增加。整幅 76×20 特征图不直接送入此候选，先选取有界稀疏点集。

按参考样本顺序执行并复用工作区，在处理块和参考样本之间设置取消检查。逐层核对离线输出，测试掩码、空集、全无对应、一对多歧义、交换输入和打乱点顺序。固定网络与资源随算法库交付，不引入动态模型图、运行时下载或多种后端框架。

是否采用 attention，以相同数据、CNN 特征和认证策略下，在目标误接受率处的误拒绝改善及 CPU／内存成本决定。对应可视化更整齐或训练损失更低不足以支持采用；没有稳定收益时保留距离匹配方案。

## 9. BRISK 局部特征候选

BRISK 的核心是局部采样、方向估计和二进制强度比较，适合自行实现。原论文同时包含检测及尺度处理 [3]；本节区分原方法与窄幅适配，避免将任意二进制描述子都称为标准 BRISK。

### 检测与尺度

预研实现采用**单尺度 FAST-9 检测 + BRISK 思路的自定义描述子**，正式算法标识应注明这一变体，不宣称与原始 BRISK 或 OpenCV 默认输出逐位兼容。固定传感器采样尺度是选择单尺度的依据；压力形变仍须由实测检验，不能宣称单尺度具备尺度不变性。

1. 将有效精度数据转换到配置明确的灰度范围，不采用 GUI 的每帧自动显示拉伸作为隐式算法步骤。
2. 自行实现半径 3 的 16 点圆周测试：至少连续 9 点同向超过中心亮度阈值，才产生候选；圆周索引首尾相接，采样越界直接排除。
3. 以能够维持圆周条件的亮度差定义响应，执行空间非极大值抑制；同分按固定坐标顺序处理，保证结果可复现。
4. 按质量、空间间隔和有效描述邻域保留至多 64 点；点不足时报告特征不足，不靠降低阈值直到凑满数量。

如果样本表明尺度处理有必要，再评价原 BRISK 的 AGAST 检测、交错尺度层和空间／尺度极值定位，或有明确范围的尺度变体。每增加一层都要计入 40 像素宽度下的边界损失与资源成本；不能直接照搬大幅图像的金字塔层数。

### 采样模式与二进制描述

预研自定义模式使用同心环，半径依次为 `0、2、4、6、8` 像素，各环采样点数为 `1、8、12、16、20`，共 57 点；各环从正 x 方向开始等角排列。它用于测试小邻域的稳定性，**不是原论文默认模式**。

平滑采样采用自行实现的局部均值：建立足够位宽的积分图，在旋转后的位置计算约定方形邻域的均值，分数坐标采用一致的插值规则。预研平滑窗口为 3×3；该规则属于变体的一部分，不声称与原论文或 OpenCV 的平滑近似完全一致。所有平滑及插值支持必须位于有效区域内，不能只检查环中心。

以固定点序枚举 `i < j` 的点对，距离小于 4 像素者为短对，大于 6 像素者为长对，中间点对不参与。通过长对估计梯度方向：将 `(I_j - I_i) × (p_j - p_i) / ||p_j - p_i||²` 求和，再用 `atan2` 得到方向。方向强度不足时丢弃该点。随后旋转采样模式，重新采样并对短对执行 `I_j > I_i` 比较，相等置 0。

描述位数等于短对数量，按固定点对顺序写入字节，最后字节未用位必须为 0。模式坐标、点对表、位序、平滑、旋转与边界规则构成同一配置版本，冻结后保存确定的表，避免不同平台的浮点比较改变点对集合。原始 BRISK 的 512 位描述子不是这个自定义模式的必然长度。

实现只需要圆周检测、积分图、采样、三角函数、数组和按位运算；不引入 OpenCV、图像库或大型预计算表。方向可按需计算；若量化方向或缓存采样模式，必须固定量化规则并测量其影响。

### 模板、录入与匹配

每点保存坐标、方向、质量及二进制描述子，样本级保存有效覆盖与模式标识。若描述位数为 `B`、点数为 `N`，描述数据为 `N × ceil(B/8)` 字节，元数据另计。模式不同的模板不可直接比较，也不能将学习得到的新点对表静默覆盖旧版本。

录入同样执行质量、一致性、重复与覆盖检查，保留有限个独立样本；不对未对齐的二进制串求平均或直接多数投票。探测点只计算一次描述子，对参考点使用异或和位计数得到汉明距离。位计数可用标准库可用能力或自写可移植实现，不强制提高现有 C++ 标准版本。

归一化汉明距离用于候选筛选，第 10 节负责几何验证和评分。1:1 与 1:N 的录入样本聚合和未知手指拒绝采用相同业务契约，阈值与 CNN 分开标定。亮度比较对部分灰度变化较稳定，并不自动解决干湿、弹性形变、脊线重复或弱方向问题。

专项验证包括各阶段保留点数、方向重复性、单个位的翻转率与相关性、对应点汉明距离分布以及跨按压几何支持。若缩小模式只增加点数却降低异指区分能力，应否定该配置。必要时研究原模式或其他二进制方法，不能把阈值放宽作为恢复认证效果的手段。

## 10. 两个局部特征候选的匹配细节

本节供 CNN 与 BRISK 局部特征候选复用，不要求相关匹配、细节点拓扑或其他方案采用相同流程。距离匹配按本节生成对应与分数；attention 变体按第 8 节生成对应与分数，再复用这里的几何验证和身份聚合。先复用已验证的数据与数学操作，不为此建立通用算法继承体系。

### 对应与几何验证

1. 穷举两个有限点集的描述距离，保留满足绝对距离门槛的双向最近邻；用最近／次近距离分辨歧义，第二候选不存在或并列近邻时采用明确的拒绝规则。若评估带多方向的配置，同一物理点的方向候选不能重复计数，次近邻须来自其他物理点。
2. 点与点保持一对一对应。从两个不同对应构造旋转和平移假设；源、目标两点都必须相距足够远，点间距离变化超过容差则排除，避免短基线与退化假设。
3. 至多 64 个对应时可枚举至多 2,016 个对应对，无需先引入随机采样框架。对每个假设计算全体重投影误差，选取支持充分、残差小且覆盖分散的结果；枚举及评分均受工作量上限和取消检查约束。
4. 对内点重新估计二维刚体变换：去中心后，以交叉项和点积的累积量通过 `atan2` 求旋转，再由两组中心求平移；使用自行实现的二维闭式计算，无需 Eigen 或 SVD 库。退化或不稳定结果失败。
5. 重算内点、有效区域重叠与残差。检查支持点沿长轴的跨度、在有效重叠中的分布及独立物理位置数量，不将两个构造点或一小簇重复脊线视为充分认证证据。

重投影阈值按采样尺度与定位误差标定，不采用论文中的任意像素阈值。刚体模型不足时可研究受约束形变；在确认收益前不加入仿射或自由形变去强行解释坏对应。

### 分数与录入样本聚合

距离匹配预研使用可解释的样本分数：通过质量、支持数量、空间覆盖和残差门槛后，令 `S = (m / min(n_probe, n_reference)) × mean(1 - d_i / d_limit)`。其中 `m` 为唯一内点数，`n` 为各样本有效物理点数，`d_i` 为内点描述距离且小于正数门槛 `d_limit`；无内点或分母为零时返回无匹配证据。

该分数只是待校准的有界相似度，不是身份概率；CNN 与 BRISK 各自使用自己的距离和门槛。其分母可能惩罚小重叠样本，需要按重叠分组检查；如改为重叠区域归一化，必须防止极少对应产生虚高分。质量、覆盖门槛同样要计入总体拒绝率，不能在比较时删除失败样本。

两个候选均以同一身份内的最高有效样本分数作为预研聚合规则。增加样本相当于增加匹配机会，必须随录入策略重新校准；不能将每个局部块或每次样本比较当作独立认证。1:N 仅在达到开放集接受条件时返回原图库身份；若多个身份满足条件但无法可靠区分，返回未匹配。

### 实现验证

用非生物合成数据验证插值、积分图、FAST 圆周边界、描述位序、汉明／欧氏距离、刚体求解和几何退化；用受控变换核对方向、平移、旋转与坐标映射。CNN 另做逐层参考计算对照，BRISK 变体建立自己的固定描述子测试向量，不以 OpenCV 默认输出作为必然一致的预期值。真实设备样本用于认证有效性评估，两类验证均须通过。

## 11. 样本、训练与决策流程

### 数据要求

保留完整原始帧并标注匿名人员、手指、设备、采集会话、独立按压和帧序号。需要同指跨按压／跨会话样本、异指样本及失败观测，不能只提供一次按压的连续清晰帧。

现有 [SQLite 录制模块](../tools/recording.py)记录手指名称、会话和帧时间，人员与独立按压信息须补充；录制会话不能自动等同于按压。原始指纹数据留在受控本地目录，不进入代码仓库。

传统方法同样需要调参和阈值校准数据。学习方法另外需要足够的训练身份与适用监督；对应点、细节点或质量标注的获得方式必须落实，不能默认依赖不可用的商业标注工具。

### 划分与标定

训练、方案选择、分数／阈值校准与最终测试按人员隔离，至少避免手指身份交叉。同次按压及其增强版本不得跨集合，评估中的录入和探测来自不同会话。

数据不足时可在开发数据内做交叉验证，但最终测试保持独立。异指与未知手指既包括其他人的手指，也应覆盖同一人的其他手指。增强不能替代真实重采样和跨会话数据，错误配准标签需要抽查与剔除。

少量设备样本可以确认格式、噪声、纹理和覆盖条件，缩小候选范围；不能充分证明最优算法或极低误接受率。每次评估都注明证据能支持的结论及缺口。

### 收到样本后的工作

| 步骤 | 产出 |
| --- | --- |
| 样本审计 | 布局、异常／重复帧、标签完整性与数据划分 |
| 成像与覆盖分析 | 可用区域、脊线尺度、质量变化、位姿和重叠分布 |
| 候选筛选 | 根据特征稳定性、标签可得性、存储与部署条件排除不适用方案 |
| 同条件比较 | 固定录入与尝试策略，比较认证效果、模板大小、耗时和资源 |
| 选择与校准 | 确定算法、预处理、录入规则、聚合与接受条件 |
| 独立验证 | 冻结配置后测试，记录分组表现、限制和发布条件 |

最终决策报告写清选择与排除依据、算法配置、必要资源及来源、模板规范和测量结果。不能用训练集准确率或几组可视化匹配替代认证评估，也不因某个方法已写入本文就继续保留。

## 12. 工程接入

职责沿用[开发指南](development.md)：C 驱动管理 USB 和 libfprint 对象，C++ 库管理算法数据、必要资源和匹配。无需训练的算法不引入模型加载；需要模型的算法不在设备录入时重新训练。

[现有 C ABI](../driver/algorithm/entry.h)是单帧同步接口，缺少完整的多次录入和质量重试表达。确定算法后再扩展确有必要的会话、状态和资源操作；不改变现有契约却私下保存借用输入指针，也不通过全局可变状态隐藏录入过程。接口变更须同步更新开发指南、适配层和测试。

同步或异步执行依据主循环预算与实测最坏耗时决定，不为所有算法强制引入线程。耗时处理必须移出主循环；异步派发时复制输入，C++ 不持有 GLib 对象，完成通知由 C 层回到原上下文。

取消既要停止后续工作，也要保证迟到结果不能再次完成动作。算法若支持合作式取消，可通过标准 C 接口传递状态，在可中断边界检查；若运行时调用不能中断，则记录其最坏延迟，保持资源有效并丢弃取消后的结果。并发与缓存策略不得超出实际会话需求。

正式特征可由 libfprint 的 `FPI_PRINT_RAW` 承载，适配层根据最终结果报告匹配。可选扫描模板允许省略，不将生物特征相似当作模板数据相等。不存在或不兼容的算法资源应返回错误，不能回退到当前旁路成功行为。

Python GUI／CLI 保留明确的开发采集通路；正式录入返回特征后，不再借该结果解码原始图像。仍使用现有统一入口，不新增重复采集工具。

## 13. 验收与交付

验收针对完整操作定义指标和分母：区分单次模板比较、一次验证动作和包含重试的登录过程。1:N 需测量未登记手指被错误接受以及已登记手指被认错／拒绝，不能仅报告闭集最高分命中率。

在相同数据划分、图库和尝试策略下，比较固定误接受率下的误拒绝率、质量拒绝、录入失败和端到端成功率。若允许不同录入样本数，应同时报告录入时间与模板成本，不把更多采集机会带来的收益全部归因于算法。

资源指标包括模板与算法资源大小、峰值内存、预处理／特征提取／完整匹配延迟及取消延迟。x86_64、ARM64 按实际支持范围分别测量，不把论文中的 GPU 耗时作为 CPU 承诺。保留必要的组件消融，只有收益明确的复杂度才进入最终方案。

报告试验数量、困难条件分组和不确定性。共享手指的大量配对不是独立试验，零次误接受不能证明任意低的误接受率。质量拒绝与录入失败不能从统计中静默删除。

测试按所选方法覆盖：

- 帧与模板解析边界、预处理一致性、版本兼容和非法输出。
- 跨按压／会话、旋转偏移、干湿压力变化、重复纹理、重叠不足。
- 多次录入中的重复按压、异指混入、质量重试、失败与取消。
- 空图库、未知手指、歧义身份、图库规模与尝试策略变化。
- 执行资源失败、并发边界和取消后的迟到完成；学习方法另测导出与训练端数值一致性。

最终交付为选定算法及必要资源、固定配置、模板规范、独立评估报告、C++ 实现、libfprint 适配和保留开发采集能力的工具。未满足验收条件时继续定位数据或算法问题，不以降低门槛或保留占位成功逻辑完成交付。

11. [SuperGlue](https://arxiv.org/abs/1911.11763)：基于上下文聚合学习对应关系，并处理不可匹配点。
12. [LightGlue](https://arxiv.org/abs/2306.13643)：局部特征的学习式匹配及计算效率研究。
